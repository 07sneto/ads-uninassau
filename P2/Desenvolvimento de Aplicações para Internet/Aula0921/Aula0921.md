## O que é node.js?

    JavaScript é a linguagem.
    Node.js é o ambiente que permite executar JavaScript fora do navegador.
#
    Antes:
    JavaScript → navegador

    Agora:
    JavaScript → Node.js → servidor
#
Pense assim: O Node.js fornece o ambiente necessário para o JavaScript trabalhar no Back-End.

## O que é um módulo?

Um módulo é uma parte do programa separada para uma responsabilidade específica.   

Em vez de colocar tudo em um único arquivo, podemos separar o código.

    Exemplo:

        app.js
        matematica.js
        usuario.js
        configuracao.js

    Isso ajuda a organizar o projeto.

### O Node.js já oferece módulos prontos.

    Alguns exemplos:
        • path → trabalha com caminhos de arquivos
        • fs → trabalha com arquivos e pastas
        • http → cria comunicação HTTP

Não precisamos instalar esses módulos.

## O que é NPM?

### NPM significa Node Package Manager.

    Ele é usado para:

        • criar e administrar projetos Node.js;
        • instalar pacotes;
        • controlar dependências;
        • executar scripts;
        • registrar informações do projeto.

    Com NPM, nosso projeto deixa de ser apenas um conjunto de arquivos.

### Criando o package.json

    Dentro da pasta do projeto, execute:
        npm init -y

    O NPM cria automaticamente:
        package.json

    Esse arquivo guarda informações importantes do projeto.

### O que é package.json?

    O package.json funciona como a “ficha” do projeto.

    Ele pode registrar:
        • nome do projeto;
        • versão;
        • descrição;
        • scripts;
        • dependências;
        • outras configurações.

    É um dos arquivos centrais de um projeto Node.js.

### Instalando um Pacote

    No terminal:
        npm install chalk

    O NPM fará algumas coisas automaticamente:
        • baixa o pacote;
        • registra a dependência;
        • cria/atualiza arquivos do projeto.
