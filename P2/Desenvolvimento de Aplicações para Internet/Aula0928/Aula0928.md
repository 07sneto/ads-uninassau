# Desenvolvimento de Aplicações para Internet - Aula 28-09

## Por que usar Express.js?

O Express.js fornece uma estrutura mais simples para construir aplicações web e APIs sobre o Node.js.

## O que é uma rota?

Uma rota define como a aplicação responde a uma combinação de:

    • método HTTP;
    • caminho (path);
    • função que será executada.
###
    Modelo:

    app.METHOD(PATH, HANDLER)

    Exemplo:

    app.get('/alunos', (req, res) => {
        
    });

## O que é um endpoint?

Endpoint é um ponto de acesso da aplicação.

    Exemplo:
        GET /alunos
        Aqui temos:
        GET → método
        /alunos → caminho
        Juntos, eles identificam uma operação da API

## O que é uma API?

API = Application Programming Interface.

    Uma API permite que diferentes partes de um sistema se comuniquem por meio de regras definidas.

    Em uma aplicação web, uma API pode receber requisições HTTP e devolver dados.

        Exemplo:
        GET /alunos
        → solicita a lista de alunos.
