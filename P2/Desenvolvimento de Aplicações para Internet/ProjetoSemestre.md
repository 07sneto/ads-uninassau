# # Desenvolvimento de Aplicações para Internet

# Projeto do Semestre

## O Desafio

	- Criar uma aplicação Web que resolva um problema real.

	- O Projeto será desenvolvido durante o semestre, acompanhando os conteúdos da disciplina.
###
	Problema > solução > interface > programação > back-end > integração

## Formação das Equipes

	- Grupos de 4 a 5 alunos.

	- Cada equipe deverá um problema e propor uma solução digital.

## Escolham um problema

	Exemplos:

	- Agendamento
	- Biblioteca
	- Eventos
	- Tarefas
	- Reservas
	- Pequenos negócios
	
## O Projeto precisa ter

	- Objetivo claro
	- Publico-alvo definido
	- Telas organizadas
	- Funcionalidades uteis
	- Front-end
	- Back-end
	- Integração

### Etapa 1 - A ideia

	Primeira Entrega -  Proposta do Projeto

	Definir:

	- Problema
	- Público-alvo
	- Solução proposta
	- 3 a 5 funcionalidades
