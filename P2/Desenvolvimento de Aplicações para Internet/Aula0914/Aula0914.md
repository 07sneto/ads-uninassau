#  JavaScript

    - Uma Linguagem de Programação.
    - Ela permite criar instruções para que o computador execute tarefas.

## Seu primeiro comando

**Código**

    console.log("Olá, turma!");

**O que significa?**

    console -> acesso ao console
    
    log() -> mostra uma informação

**Resultado no terminal**

    Olá, Turma!

### Como executar um arquivo JS?

1 - Criar arquivo "app.js"

2 - Escrever "console.log("Olá, mundo!");"

3 -  Abrir o terminal e escrever "node app.js"

## Variáveis

Uma váriavel é um nome que usamos para guardar um valor.

**Código**

    const nome = "Ana";

###
    const -> forma de declarar
    nome -> nome da variavel
    = -> recebe o valor
    "Ana" -> valor armazenado

## const e let

**const**

- quando o valor não será retribuido.

**código**

    const curso = "ADS";
###
**let**

- use quando o valor pode mudar durante o programa.

**código**

    let semestre = 1;
    semestre = 2;
