## Aula01

### Algoritmos
Sequência de passos lógicos, finitos, ordenaods que podem receber dados de entrada e produza dados de saída, para se resolver um problema.

### Formas de representação de um Algoritmo

    Texto (descrição narrativa)
        - extenso
        - ambíguo

        - português

    Fluxograma
        - extenso

        - padrão internacional
        - notação gráfica

    Pseudocódigo
        - falta de padronização

        - junção da descrição narrativa
          com uma linguagem de programação.
        - Flexibilidade

    Codigo
        - rígido quanto a sintaxe
        - regras

        - execução em tempo real

## Aula02 - Fundamentos de Java

### Paradigma de programa
São formas de escrita de código para se resolver um problema.

    Exemplos:
        - funcional / estruturado
        - orientado a objetos

### Caracteristicas do Java

    - Portabilidade
        Executa em diferentes sistemas operacionais.

    - Multithreading
        Execução do programa em diferentes núcleos da CPU.
    
    - Segurança
        Dá suporte a bibliotecas de criptografia e também a chaves Hash SHA-256 Bits.

    - Arrays
        Da suporte a listas estáticas e dinâmicas, com N dimensões.

### Tipos de Dados em Java

    - String: lista de caracteres que aceita números, letras, e caracteres especiais.
    Ex: "Daniel", "1", "F@3#!"

    - Char: representação para um único caracter.
    Ex: 'A', '1', '@'

    - float/double: representação para números decimais.
        float: Precisão Simples
        double: Precisão Dupla

    - short/byte/int/long: representação númerica para números inteiros.

### Variável
É a alocação de um espaço na memória para o armazenamento de um valor de um algum tipo.
