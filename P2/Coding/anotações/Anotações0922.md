# Array

Também conhecidos como "Arrays" ou "Lists" no idioma Inglês, ou vetores ou listas no idioma português.

E também servem para armazenar em **ordem**, alguns **dados**.

Um Array é uma estrutura que armazena vários dados de um mesmo tipo.

---

É uma coleção de grupo de valores diferenciados por uma única váriavel.

    - Acesso por meio de um índice inteiro;
    - Arrays podem ser modificados;
    - Pode-se incluir e remover itens do array.
